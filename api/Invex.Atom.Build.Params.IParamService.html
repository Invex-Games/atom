Defines a service for resolving and managing build parameters from various sources.

public interface IParamService

Remarks

The service resolves parameters from the following sources in order of precedence:

  1. Cache (if enabled)
  2. Command-line arguments
  3. Environment variables
  4. Configuration files (e.g., appsettings.json)
  5. Secret providers
  6. Interactive console prompts
  7. Default value

This service is central to the framework's parameter handling, providing features for type conversion, secret masking, and caching.

PrefetchSecretsAsync(IEnumerable<string>, CancellationToken)

Asynchronously resolves the given secret parameters from the registered ISecretsProvider instances and caches the results, so that later synchronous GetParam calls do not block on provider network calls.

Task PrefetchSecretsAsync(IEnumerable<string> paramNames, CancellationToken cancellationToken)

Parameters

paramNames IEnumerable<string>

The names of the parameters to prefetch. Parameters that are not secrets, that do not allow Secrets, that were already prefetched, or that can be resolved from the cache, command-line arguments, environment variables or configuration are skipped.

cancellationToken CancellationToken

A token passed to each GetSecretAsync(string, CancellationToken) call.

Returns

Task

A task that completes when all requested secrets have been queried.

Remarks

The build executor calls this for the secret parameters of every target that will run, using the build's cancellation token. A secret that is not prefetched is still resolved on demand by blocking on the providers. The default implementation does nothing.
