Provides extension members for querying IBuildOption instances from option collections and build definitions.

public static class BuildOptionExtensions
Inheritance
object
BuildOptionExtensions

Remarks

Members are exposed as static extensions on the option type itself, e.g. MyOption.Get(options) or MyToggleOption.IsEnabled(definition). When multiple options of the same type are present, the last occurrence wins.
