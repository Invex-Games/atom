Remarks

This interface defines the AtomArtifacts parameter, which is used by targets like IStoreArtifact and IRetrieveArtifact to identify which artifacts to process. The parameter is typically supplied via the --atom-artifacts command-line argument or an environment variable.

Properties

AtomArtifacts

Gets the names of the artifacts to be processed.

[ParamDefinition("atom-artifacts", "The name of the artifact/s to work with, use ',' to separate multiple artifacts", ParamSource.All, null)]
string[] AtomArtifacts { get; }

Property Value

string[]

Examples

If the command-line argument --atom-artifacts "Package,Symbols" is provided, this property will return ["Package", "Symbols"].

Remarks

This parameter specifies which artifacts to store or retrieve. Multiple names can be provided as a comma-separated string, which the framework parses into an array. If no value is provided, it defaults to an empty array.
