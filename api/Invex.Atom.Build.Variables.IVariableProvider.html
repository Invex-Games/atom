Defines a provider for reading and writing workflow variables to a specific storage backend.

[PublicAPI]
public interface IVariableProvider

Examples

public class CustomVariableProvider : IWorkflowVariableProvider
{
    public async Task<bool> WriteVariable(string variableName, string variableValue, CancellationToken cancellationToken)
    {
        // Custom logic to write to an external system
        return await WriteToExternalSystemAsync(variableName, variableValue);
    }
    public async Task<bool> ReadVariable(string jobName, string variableName, CancellationToken cancellationToken)
    {
        // Custom logic to read from an external system
        var value = await ReadFromExternalSystemAsync(jobName, variableName);
        return value != null;
    }
}

Remarks

This interface is part of Atom's extensible variable management system. Multiple providers can be registered, and the IVariableService will delegate operations to them in a chain of responsibility.

Implementations should return true if they successfully handle an operation, or false to allow the next provider in the chain to attempt it.
