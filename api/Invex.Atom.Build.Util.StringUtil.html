GetLevenshteinDistance(string?, string?)

Calculates the Levenshtein distance between two strings.

public static int GetLevenshteinDistance(this string? @string, string? compareTo)

Parameters

string string
compareTo string

The target string to compare to.

Returns

int

The Levenshtein distance as an integer. Returns 0 if both strings are null or empty. If one string is null/empty and the other is not, returns the length of the non-empty string.

Examples

"kitten".GetLevenshteinDistance("sitting"); // Returns 3
"".GetLevenshteinDistance("abc"); // Returns 3
"test".GetLevenshteinDistance("test"); // Returns 0

SanitizeForLogging(string?, bool, int)

Sanitizes a string for safe logging by removing or replacing problematic characters and optionally truncating it.

public static string? SanitizeForLogging(this string? @string, bool stripNewlines = true, int maxLength = 4096)

Parameters

string string
stripNewlines bool

If true, replaces newline characters with spaces. Defaults to true.

maxLength int

The maximum length of the returned string. Defaults to 4096 characters.

Returns

string

The sanitized string, or null if the input was null. If truncated, the string ends with "...".

Examples

"Hello\nWorld".SanitizeForLogging(); // Returns "Hello World"
new string('A', 5000).SanitizeForLogging(maxLength: 100); // Returns "AAAA... (97 more A's)"
"Normal text".SanitizeForLogging(); // Returns "Normal text"

SanitizeSecrets(string?, IEnumerable<string>)

Sanitizes a string by replacing specified secret substrings with asterisks or a fixed mask, ensuring that the secrets are not exposed in logs or outputs.

public static string? SanitizeSecrets(this string? @string, IEnumerable<string> secrets)

Parameters

string string
secrets IEnumerable<string>

A list of secret substrings to be sanitized from the input string. Secrets that are null or empty will be ignored.

Returns

string

The sanitized string with secrets replaced, or null if the input string was null or empty, or if no valid secrets were provided. If the input string is shorter than the shortest valid secret, it will be returned unchanged.
