Retries an asynchronous operation produced by a factory when it faults. A new task is created for each attempt.

public static Task WithRetry(this Func<Task> taskFactory, int retryCount = 5, TimeSpan retryDelay = default, CancellationToken cancellationToken = default)

A delegate that creates a new System.Threading.Tasks.Task for each attempt.

retryCount int

The number of retries to attempt after the initial failure.

The delay between retry attempts. Defaults to 1 second if not specified.

cancellationToken CancellationToken

A token to observe before each attempt and during delays.

Returns

A task that completes when an attempt succeeds, or throws an System.AggregateException after all retries fail.

WithRetry(Task?, int, TimeSpan)

Retries awaiting the provided System.Threading.Tasks.Task when it faults, up to a specified number of attempts.

public static Task WithRetry(this Task? task, int retryCount = 5, TimeSpan retryDelay = default)

Parameters

task Task

The task to await. If null, a completed task is returned.

retryCount int

The number of retries to attempt after the initial failure.

retryDelay TimeSpan

The delay between retry attempts. Defaults to no delay.

Returns

Task

A task that completes when the underlying task succeeds, or rethrows the original exception (wrapped in an System.AggregateException when multiple attempts fail) after all retries are exhausted.

Remarks

Cancellation-related exceptions are immediately rethrown and do not trigger a retry.

Note that awaiting the same System.Threading.Tasks.Task instance again does not re-execute the underlying operation; once the task has faulted, every subsequent await observes the same failure. To re-execute the operation on each attempt, use the WithRetry(Func<Task>, int, TimeSpan, CancellationToken) overload instead.
