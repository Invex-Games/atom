Represents a single error encountered while parsing command-line arguments.

[PublicAPI]
public sealed record ParseError
Inheritance
object
ParseError

Examples

For the command atom Bild (a typo of a target named Build), a ParseError is created with Message = "Unknown argument 'Bild'" and SimilarCommands containing "Build".

Remarks

Instances of this record are created by the Invex.Atom.Build.Args.CommandLineArgsParser and stored on Errors. Parsing never throws or logs; errors are reported after the application host is fully constructed, so that all output can be masked for secrets.
