Enables GitVersion-based build identification and versioning for the build.

[PublicAPI]
public interface IGitVersion

Remarks

Inheriting this interface on a build definition replaces the default IBuildIdProvider and IBuildVersionProvider registrations with implementations that derive the build ID and version from GitVersion (https://gitversion.net), based on the repository's Git history and the GitVersion.yml configuration.
