Defines a contract for retrieving sensitive configuration values (secrets) from a secure storage provider.

[PublicAPI]
public interface ISecretsProvider

Examples

// 1. Implement the interface
public class MySecretsProvider : ISecretsProvider
{
    public string? GetSecret(string key) => MySecureStore.Get(key);
}
// 2. Register the provider in your build definition
public override void ConfigureDefinitionHost(IHostApplicationBuilder builder)
{
    builder.Services.AddSingleton<ISecretsProvider, MySecretsProvider>();
}
// 3. Use a secret parameter in a target
[SecretDefinition("my-api-key", "An API key.")]
string MyApiKey => GetParam(() => MyApiKey);

Remarks

This interface is the core of the Atom framework's secret management system, enabling secure retrieval of sensitive data like API keys and connection strings. Implementations can integrate with various backends such as Azure Key Vault or .NET User Secrets.

The framework automatically discovers and queries registered providers when resolving parameters marked with SecretDefinitionAttribute. Providers are queried in descending Priority order (ties preserve registration order), creating a fallback chain (e.g., from a cloud provider to local user secrets).

Properties

Priority

Gets the resolution priority of the secrets provider.

int Priority { get; }

Property Value

int

Remarks

Providers with a higher priority value are queried first when resolving secrets among multiple providers; providers with equal priority are queried in registration order. The default value is 0.

Methods

GetSecret(string)

Retrieves a secret value by its key.

string? GetSecret(string key)

Parameters

key string

The unique identifier for the secret to retrieve.

Returns

string

The secret value associated with the key, or null if the secret is not found in this provider.

Remarks

Implementations should return null rather than throwing an exception if a key is not found, allowing the framework to query other registered providers.
