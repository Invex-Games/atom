Remarks

Keys are compared by their default equality, which for build definitions and helpers is reference equality. The cache is thread-safe and holds its entries for the lifetime of the cache instance, so typically it is stored in a static readonly field.

Typical use is to compute an expensive per-build value once, e.g. via GetOrAdd(IBuildAccessor, Func<IBuildAccessor, T>).
